Superset đọc trực tiếp cơ sở dữ liệu SQLite hoặc PostgreSQL thông qua SQLAlchemy driver. Dữ liệu sau khi được script src/data_pipeline.py của Python làm sạch sẽ được lưu vào bảng jobs_data và sẵn sàng để Superset phân tích mà không cần code thêm backend.
